# Outline Panduan Literasi AI

Total Target: 200+ Halaman
Pendekatan: 30% Teori, 70% Praktik (Latihan, Kode, Prompt).

## Bagian I: Fondasi AI (Halaman 1-40)

### Bab 1: Pengantar Kecerdasan Buatan
*   Apa itu AI? (Definisi sederhana vs teknis).
*   Sejarah Singkat (Dari Turing ke Transformer).
*   Jenis AI: ANI (Narrow), AGI (General), ASI (Super).
*   Machine Learning vs Deep Learning vs Generative AI.
*   *Latihan 1: Identifikasi AI di Sekitar Kita.*

### Bab 2: Bagaimana LLM Bekerja? (Tanpa Matematika Rumit)
*   Analogi "Probabilistic Parrot".
*   Tokenisasi: Bagaimana AI membaca teks.
*   Training Data: Dari mana pengetahuan berasal.
*   Hallucination: Mengapa AI bisa berbohong.
*   Context Window: Memori jangka pendek AI.
*   *Studi Kasus: Membedah respons ChatGPT.*

## Bagian II: Prompt Engineering Praktis (Halaman 41-90)

### Bab 3: Dasar-dasar Prompting
*   Anatomi Prompt yang Baik (Role, Context, Instruction, Constraint).
*   Zero-shot vs One-shot vs Few-shot Prompting.
*   Teknik: Chain of Thought (CoT).
*   Teknik: ReAct (Reason + Act).
*   *Workshop: Memperbaiki Prompt yang Buruk.*

### Bab 4: Pola Prompt Lanjutan
*   Persona Pattern.
*   Audience Persona Pattern.
*   Flipped Interaction Pattern (AI bertanya pada Anda).
*   Game Play Pattern.
*   Recipe Pattern.
*   *Cheat Sheet: 10 Pola Prompt Wajib Tahu.*

### Bab 5: AI untuk Produktivitas (Studi Kasus)
*   Writing Assistant (Brainstorming, Editing, Formatting).
*   Coding Assistant (Debugging, Refactoring, Explaining).
*   Data Analysis (Menggunakan Advanced Data Analysis).
*   Image Generation (Midjourney/DALL-E basics).

## Bagian III: Implementasi Teknis & Coding (Halaman 91-150)

### Bab 6: Menyiapkan Lingkungan Pengembangan
*   Instalasi Python & VS Code.
*   Virtual Environment (venv/conda).
*   Jupyter Notebooks.
*   Menginstall Library AI (`openai`, `langchain`, `transformers`).

### Bab 7: Berinteraksi dengan API
*   Mendapatkan API Key (OpenAI/Anthropic).
*   Struktur Request JSON.
*   Membuat Chatbot Sederhana dengan Python.
*   Streaming Responses.
*   Cost Management (Menghitung Token).

### Bab 8: Retrieval Augmented Generation (RAG) Dasar
*   Masalah Knowledge Cutoff.
*   Konsep Vector Database (Embeddings).
*   Membangun "Chat with your PDF" sederhana.
*   *Proyek Akhir Bagian III: Bot Customer Service.*

## Bagian IV: Etika, Keamanan, dan Masa Depan (Halaman 151-180)

### Bab 9: Etika dan Keamanan AI
*   Bias dan Fairness.
*   Privacy & Data Security (Jangan upload rahasia perusahaan!).
*   Deepfakes dan Misinformasi.
*   Prompt Injection Attacks (Dasar keamanan).

### Bab 10: Masa Depan Pekerjaan
*   Augmentasi vs Otomasi.
*   Skill Baru yang Dibutuhkan.
*   Multimodal AI (Video, Audio, Teks terintegrasi).
